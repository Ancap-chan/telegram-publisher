# Сборка приложения для Windows

## Подготовка

1. Установи Python 3.11 или новее вместе с Python Launcher (команда `py`).
2. Убедись, что в Windows доступен WebView2 Runtime, необходимый для окна редактора.
3. Закрой запущенный экземпляр приложения перед сборкой.

## Сборка

Запусти PowerShell из корня проекта и выполни:

```powershell
.\scripts\build_windows.ps1
```

Сценарий автоматически пересоздаёт отдельное виртуальное окружение `.venv-build`, обновляет в нём pip, устанавливает проект с дополнительными зависимостями разработки и сборки, проверяет согласованность зависимостей и запускает тесты. Если установка, проверка зависимостей или тесты завершаются ошибкой, упаковка не выполняется.

Приложение собирается в режиме PyInstaller `--onefile`: все необходимые компоненты упаковываются в один исполняемый файл. Результат находится по пути `dist\Telegram Publisher.exe`; папка `_internal` рядом с EXE не нужна. При запуске PyInstaller автоматически распаковывает внутренние компоненты во временную папку, поэтому первый запуск может занимать немного больше времени. Для работы интерфейса по-прежнему требуется WebView2 Runtime в Windows.

При установке выбираются актуальные версии, удовлетворяющие диапазонам в `pyproject.toml`. Поэтому результат сборки не гарантированно побитово воспроизводим между разными датами. Файл `dist\build-dependencies.txt` сохраняет фактически установленные версии для диагностики.

Сценарий удаляет и создаёт заново только выделенное окружение `.venv-build`. Существующее окружение разработки `.venv` не меняется. Если в `dist` осталась папка от прежней сборки в режиме `onedir`, она не нужна для запуска нового одиночного EXE.

Если PowerShell запрещает запуск сценария, открой его из VS Code или запусти из терминала VS Code с подходящими для своей системы настройками выполнения сценариев. Не меняй системную политику выполнения только ради сборки.

## Проверка собранного приложения

Перед распространением скопируй только `Telegram Publisher.exe` в отдельную временную папку и запусти его оттуда. Проверь:

- редактор открывается одним окном, без повторного запуска процесса;
- руководство открывается отдельным окном, а редактор остаётся доступен;
- приложение закрывается без оставшегося фонового процесса;
- профили каналов читаются и сохраняются, токены остаются в системном хранилище учётных данных Windows;
- открытие и сохранение черновика работают;
- ошибка сети и частичная публикация показывают состояние и позволяют повторить отправку остатка;
- после успешной публикации содержимое редактора остаётся на месте.

Автоматические тесты запускаются сценарием сборки командой `.venv-build\Scripts\python.exe -m pytest`. Это не заменяет запуск собранного EXE на Windows.
