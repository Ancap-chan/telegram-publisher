# Telegram Publisher

Локальный инструмент для публикации подготовленных постов в Telegram.

## Планируемые возможности

- Получение текста из буфера обмена.
- Предпросмотр и подтверждение перед публикацией.
- Публикация коротких постов одним сообщением.
- Подготовка длинных публикаций с сохранением форматирования и учётом ограничений Telegram.
- Понятная обработка ошибок отправки.

## Требования

- Python 3.11 или новее.
- Git для работы с репозиторием.
- Telegram-бот с правом публикации в целевом канале.

## Установка для разработки

1. Создайте виртуальное окружение: `py -m venv .venv`.
2. Активируйте его: `.venv\Scripts\Activate.ps1`.
3. Установите проект: `python -m pip install -e ".[dev]"`.
4. Скопируйте `.env.example` в `.env` и заполните настройки.

Токен бота хранится только в локальном файле `.env`. Не публикуйте его и не добавляйте в Git.

## Запуск

После реализации основной функциональности программа будет запускаться командой `python -m telegram_publisher`.

На текущем этапе создан только каркас проекта; публикация сообщений ещё не реализована.

## Проверки

Запуск тестов: `python -m pytest`.
