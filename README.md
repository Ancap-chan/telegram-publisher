# Telegram Publisher

Локальное графическое приложение для подготовки и публикации постов в Telegram.

## Возможности текущей версии

- Оконный интерфейс на Tkinter.
- Вставка текста из буфера обмена.
- Выбор изображения для публикации.
- Предварительный подсчёт длины текста и числа частей.
- Отправка в Telegram-канал через бота.
- Разбиение длинного обычного текста на сообщения с ограничением Telegram.
- Для публикации с изображением первая часть текста используется как подпись, остальные части отправляются отдельными сообщениями.
- Отображение ошибок и результата отправки.

## Требования

- Python 3.11 или новее.
- Telegram-бот с правом публиковать сообщения в целевом канале.

## Установка для разработки

1. Создай виртуальное окружение: `py -m venv .venv`.
2. Активируй его в PowerShell: `.venv\Scripts\Activate.ps1`.
3. Установи проект: `python -m pip install -e ".[dev]"`.
4. Скопируй `.env.example` в `.env` и заполни настройки.

В файле `.env` должны быть заданы:

```dotenv
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=@имя_публичного_канала
```

Вместо публичного имени канала можно указать его числовой идентификатор. Токен хранится только в локальном файле `.env`; не публикуй его и не добавляй в Git.

## Запуск

Из активированного виртуального окружения выполни:

```powershell
python -m telegram_publisher
```

Приложение откроется в отдельном окне. Консоль на этом этапе нужна только для запуска в режиме разработки; позднее можно подготовить сборку в `.exe`.

## Ограничения текущей версии

- Отправляется обычный текст без сохранения форматирования из редактора WordPress.
- Текст разбивается на части по абзацам и словам, когда это возможно.
- Если добавлено изображение, первая часть текста ограничена размером подписи Telegram; продолжение отправляется следующими сообщениями.
- Перед публикацией приложение показывает подтверждение. Отправка нескольких частей не является транзакцией: при сетевой ошибке часть публикации может уже оказаться в канале.
