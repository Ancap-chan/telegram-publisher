# Telegram Publisher

Локальное графическое приложение для подготовки и публикации постов в Telegram.

## Возможности текущей версии

- Оконный интерфейс на Tkinter.
- Визуальный редактор автоматически открывается при запуске и содержит выбор канала, способа публикации и команду отправки.
- Вставка текста и изображений из буфера обмена сочетанием Ctrl+V сохраняет доступное браузеру форматирование; контекстное меню по правой кнопке мыши включает вырезание, копирование и вставку.
- Доступны жирный/курсивный/подчёркнутый/зачёркнутый текст, заголовки, цитаты, списки, таблицы, ссылки, а также вставка изображений и видео по публичному URL.
- Управление несколькими профилями каналов и выбор канала перед публикацией.
- Хранение токенов ботов в системном хранилище секретов Windows; в файле настроек сохраняются только названия профилей и идентификаторы каналов.
- Импорт первого профиля из локального файла `.env`, если он существует.
- Предварительный подсчёт длины текста и выбор способа публикации по длине и наличию изображения.
- Короткий текст можно отправить как подпись к изображению.
- Поддержка Bot API `sendRichMessage`: до 32768 символов, HTML-форматирование и встроенное изображение.
- Опциональная разбивка текста на серию обычных или рич-сообщений.
- Отображение ошибок и результата отправки.

## Требования

- Python 3.11 или новее.
- Telegram-бот с правом публиковать сообщения в целевом канале.

## Установка для разработки

1. Создай виртуальное окружение: `py -m venv .venv`.
2. Установи проект и инструменты тестирования: `.venv\\Scripts\\python.exe -m pip install -e ".[dev]"`.
3. Запусти приложение: `.venv\\Scripts\\python.exe -m telegram_publisher`.

Активация окружения в PowerShell необязательна. Если политика выполнения сценариев блокирует `Activate.ps1`, используй команды через `.venv\\Scripts\\python.exe`.

## Настройка каналов

1. Нажми «Настроить каналы…».
2. Создай профиль, указав название, токен Telegram-бота и имя публичного канала (например, `@my_channel`) или числовой ID.
3. Добавь бота в канал и выдай ему право публикации.
4. При наличии нескольких профилей выбери нужный в списке «Канал» перед нажатием «Опубликовать».

Токены хранятся через системное хранилище учётных данных. В локальном файле настроек сохраняются только названия профилей и идентификаторы каналов. Не отправляй токен в чат и не добавляй его в Git.

Для обратной совместимости приложение ищет `.env` в текущей папке, рядом с проектом или рядом с собранным исполняемым файлом. Если сохранённых профилей нет и в `.env` заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, приложение автоматически создаёт профиль «Канал из .env» и сохраняет токен в системном хранилище, если оно доступно.

## Ограничения текущей версии

- Визуальный редактор объединяет подготовку и публикацию. После подтверждения отправки приложение возвращается к редактору; результат последней публикации или ошибка отображаются в строке состояния.
- Изображения и видео добавляются по публичному URL; выбор локального файла не предусмотрен.
- Обычное сообщение ограничено 4096 символами, подпись к изображению — 1024, рич-сообщение — 32768 символами.
- При включённой серии текст разбивается по абзацам и словам, когда это возможно. Если разметка HTML пересекает границу частей, её следует проверить вручную.
- Перед публикацией приложение показывает подтверждение. Отправка нескольких частей не является транзакцией: при сетевой ошибке часть публикации может уже оказаться в канале.

## Проверки

Запуск тестов: `.venv\\Scripts\\python.exe -m pytest`.
